## 💡 Sobre este repositório

Este é o código-fonte do meu **portfólio profissional**, desenvolvido para apresentar minhas habilidades, projetos e forma de trabalhar como **Desenvolvedora Full-Stack**. O site é 100% responsivo, rápido e pensado para converter visitantes em oportunidades — seja uma vaga, uma parceria ou um cliente.

> 🎯 Foco em código limpo, arquitetura escalável e experiência do usuário — unindo performance na interface e segurança na nuvem.

## 🙋‍♀️ Sobre mim

Sou **Desenvolvedora** e estudante de **Análise e Desenvolvimento de Sistemas** na Unipê. Meu foco é construir plataformas que funcionem perfeitamente de ponta a ponta, gerenciando desde a criação do banco de dados relacional até a entrega de uma interface responsiva e de alta conversão.

Minha experiência anterior em atendimento corporativo me deu uma comunicação clara e assertiva — porque um bom projeto não se resume a escrever código, mas a entender a real necessidade do cliente, alinhar expectativas e entregar soluções robustas dentro do prazo.

**Disponível para projetos freelance e oportunidades de trabalho.** ✅
